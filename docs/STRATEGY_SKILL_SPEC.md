# GuardRail Strategy Skill Spec

## Track

BNB Hack: AI Trading Agent Edition - Track 2, Strategy Skills.

## Skill Summary

GuardRail Strategy Skill turns CoinMarketCap-style market data into a backtestable crypto trading strategy. The core idea is risk-first routing: the skill does not simply chase signals, it first classifies the market regime, selects a suitable strategy, and then applies a risk governor that can block trades.

## Intended CMC Inputs

The skill expects normalized market data from CoinMarketCap Agent Hub or Data API.

```ts
type Candle = {
  time: string
  open: number
  high: number
  low: number
  close: number
  volume: number
  marketCap: number
}
```

Recommended CMC sources:

- OHLCV price history
- Volume and liquidity fields
- Technical indicators such as RSI, MACD, EMA, or CMC pre-computed technicals
- Optional sentiment, Fear & Greed, derivatives, funding, and news signals

The demo can run in two modes:

- Deterministic sample OHLCV data, so the strategy can be reviewed without API keys.
- CoinMarketCap cache generated by `npm run fetch:cmc`, so a submission can be built with CMC data without exposing the API key in the browser. The script uses historical OHLCV when the plan supports it; otherwise it falls back to latest CMC quote data and calibrates the demo history around live CMC price, volume, and market cap.

## Market Regime Detection

The skill classifies the latest market state into one of five regimes:

- `Trend Expansion`: short moving average above long moving average and positive slope.
- `Range Rotation`: no strong trend, suitable for mean reversion.
- `High Volatility`: ATR percentage exceeds the configured threshold.
- `Low Liquidity`: volume is weak relative to recent average or below liquidity threshold.
- `Risk-Off`: negative slope and price below long moving average.

## Strategy Router

The selected regime determines the strategy:

- `Momentum Follow`: used in trend expansion.
- `Mean Reversion`: used in range rotation.
- `Volatility Breakout`: used only when volatility is high and volume confirms the move.
- `Capital Preservation`: used in risk-off or low-liquidity conditions.

## Risk Governor

All buy signals must pass the risk governor:

- Max drawdown limit
- Max position percentage
- Minimum confidence threshold
- Stop loss
- Take profit
- Cooldown after losing trades

Risk modes:

- `Defensive`: lower drawdown and position limits.
- `Balanced`: default mode.
- `Growth`: higher position limits and wider stops.

## Backtest Rules

- Starting equity: 10,000 USD.
- Long-only spot strategy.
- One position at a time.
- Entry occurs when router emits `buy` and risk governor approves.
- Exit occurs on stop loss, take profit, router sell signal, or final close.
- Reported metrics: total return, max drawdown, win rate, profit factor, exposure, risk overrides, and Sharpe-like score.

## Benchmark

GuardRail is compared against a naive RSI 35/65 baseline:

- Buy with 100% available cash when RSI is below 35.
- Sell when RSI is above 65.
- No market regime detection.
- No position sizing.
- No drawdown governor.
- No cooldown after losses.

The dashboard reports return delta and drawdown saved versus this baseline. This is the main proof point: GuardRail should be evaluated on risk-adjusted behavior, not only headline PnL.

## Why This Is Different

Most simple trading skills emit indicator-based buy and sell signals. GuardRail is designed around trade refusal. It explains when it should not trade, exposes every risk override, and compares itself against a naive indicator baseline.

The intended claim is not "guaranteed profit." The intended claim is that GuardRail produces explainable, backtestable, risk-aware strategy decisions that are safer to evaluate and easier to improve than raw indicator rules.
